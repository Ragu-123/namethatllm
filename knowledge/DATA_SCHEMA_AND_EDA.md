## 2. Dataset Schema & Column Details

### `train.csv`
- Total rows: **2,699**
- Missing / Null values: **0** across all columns
- Columns:
  1. `id` (`object` / string): Unique 12-character hex ID for the passage (e.g. `0018b3765972`).
  2. `prompt_id` (`object` / string): Identifier for the hidden prompt, formatted as `p001` through `p150` (150 unique prompts).
  3. `text` (`object` / string): The raw text response generated by the specified model.
  4. `model` (`object` / string): Ground truth target model name (18 unique classes).

### `test.csv`
- Columns:
  1. `id` (`object` / string): Unique passage ID.
  2. `text` (`object` / string): The passage generated by an unknown LLM.
- ⚠️ **CRITICAL NOTE**: `prompt_id` is **NOT** present in `test.csv`. The test set consists of standalone text passages from unseen prompts!

### `sample_submission.parquet`
- Columns: `['id', 'model']`
- Data types: `id`: string, `model`: string.

## 3. Experimental Design: Matched-Prompt Structure

The training set was generated using a **strictly balanced factorial design**:
- There are **150 prompts** (`prompt_id`: `p001` to `p150`).
- For **149 of the 150 prompts**, all **18 models** generated an answer ($149 \times 18 = 2,682$).
- For exactly **1 prompt**, 17 models generated an answer (missing `claude-fable-5`), giving $2,682 + 17 = 2,699$ total training passages.
- This crosstab is binary (either 0 or 1 passage per prompt-model combination).

## 4. Text Characteristics & Length Distribution

- **Passage Format**: Every passage is a single, self-contained paragraph with **no Markdown headings**, bullet points, or numbering.
- **Character Length**:
  - Minimum: 230 characters
  - Median: 670 characters
  - Maximum: 1,900 characters
- **Word Count** (whitespace split):
  - Minimum: 36 words
  - Median: 101 words
  - Maximum: 274 words
- **Token Count** (standard BPE / SentencePiece):
  - Longest passage is approximately ~370 BPE tokens.
  - Fits comfortably within standard sequence lengths (e.g. `max_length=512`).

## 5. Nature of Prompts (from pjmathematician reconstruction)

Reconstruction of all 150 prompts reveals that the generation prompts consist primarily of:
1. **Instructional Format**: "Explain concept X vividly", "Describe Y using an everyday analogy", "Narrate Z for an educated general audience".
2. **Key Domains**: Physics (32), Biology (28), Philosophy (21), Creative prose (16), Mathematics (15), History (12), Computer Science (10), Psychology (6), Economics (5).
3. **Specific Concepts**: Jevons paradox, Stern-Gerlach experiment, slime mold railway optimization, Hilbert's infinite hotel, standing on a neutron star surface, Dutch Hunger Winter epigenetics.
4. **Style Directives**: "whimsical", "poetic", "haunting", "rigorous yet accessible".
5. **Random Length Targets**: Each generation was prompted with an independent random length requirement (explaining the 40–270 word range).
